Character

Click a name to edit it as ‘Display name/EnglishName’. The display name appears in the game; the English name becomes the folder name.
Click an expression slot to pick an image. When you press ‘Save’ it is copied to the game folder as Characters/EnglishName/expressioncode.png.
Characters overlay the full 16:9 screen, the same as backgrounds. Draw on a transparent PNG with empty space above the head and on both sides; wings and particles can go anywhere on screen. The larger you draw (e.g. 1920 × 1080), the sharper it looks. The dotted line is the area the dialogue box covers. Animated GIF · WebP · APNG also work.

UI

The left side is a preview. In ‘Screen elements’ on the right, click an element such as the dialogue box or name box, change its position and size with sliders, and pick an image with ‘Choose resource’.
Fonts and text size · color are also set in the right panel. When you press ‘Save’, images go to the UI folder and layout and text settings go to UI/Layout.json.

Background

Names use the form ‘Background name/BackgroundName’. The English name becomes the file name, and in dialogue you pick it as bg_EnglishName.
Click an image to pick a file; when you press ‘Save’ it is copied as Backgrounds/EnglishName.png. A 16:9 ratio can be larger, like 1920 × 1080. Animated GIF · WebP · APNG also work.

Ending

Create an ending and name it in the form ‘Ending title/ENDINGNAME’. When an ending block in the Dialogue tab picks this ending, its title and cutscene appear on the ending screen.
Cutscenes are 16:9 images (PNG · animated GIF · WebP · APNG); when you press ‘Save’ they are copied as Endings/EnglishName.png etc. You can also go without a cutscene. Change the text · button positions of the ending screen in the UI tab.

Sound

Names use the form ‘Sound name/SoundName’. Click the note to pick a sound file; when you press ‘Save’ it is copied to the Sounds/BGM or Sounds/SFX folder.
The ★ on BGM marks the main BGM (MAIN in dialogue). If you also target iPhone, mp3 is recommended.
